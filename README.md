# بوابة الرياضيات — النسخة المطوّرة

واجهة عربية RTL أكثر حداثة وتجاوباً مع الهاتف، باستخدام HTML وCSS وJavaScript دون مكتبات خارجية.

## الملفات
- `index.html` بنية الموقع.
- `style.css` التصميم المحسّن والوضع الداكن.
- `app.js` الدروس النموذجية، التمارين، النقاط، والتنقل مع دعم زر الرجوع.

## زر الرجوع
يوجد زر رجوع داخل صفحات الدرس والمحور، كما أضيف دعم زر الرجوع في المتصفح/الهاتف للعودة إلى الشاشة السابقة داخل الموقع.

## النشر
ارفع الملفات الثلاثة إلى جذر مستودع GitHub، ثم فعّل Settings → Pages → Deploy from a branch → main → /(root).

## تنبيه
المحتوى ما زال نموذجاً أولياً ويحتاج إلى استكمال جميع دروس المنهاج والتحقق من صحتها قبل اعتماده للتدريس.
