# بوابة الرياضيات — نسخة أولية قابلة للتطوير

موقع عربي RTL متجاوب مع الهاتف، مبني باستخدام HTML وCSS وJavaScript فقط، دون مكتبات أو خادم أو اشتراك.

## محتويات الحزمة
- `index.html`: بنية الصفحات.
- `style.css`: الهوية البصرية والتصميم المتجاوب.
- `app.js`: الدروس النموذجية، التنقل، الأسئلة والتغذية الراجعة والنقاط وحفظ المظهر.

## التشغيل
افتح `index.html` في المتصفح أو ارفع الملفات الثلاثة إلى مستودع GitHub ثم فعّل GitHub Pages من إعدادات المستودع.

## ملاحظات مهمة
هذه نسخة MVP أولية بمحتوى توضيحي تفاعلي لأربعة محاور، وليست بعدُ تغطية كاملة لدروس المنهاج السوري. يجب مراجعة محتوى كل صف وإضافة الدروس والتمارين وأوراق العمل قبل اعتماد الموقع تعليمياً. لا توجد حالياً حسابات طلاب أو لوحة متصدرين مشتركة بين الأجهزة؛ النقاط تحفظ محلياً في متصفح الطالب.
