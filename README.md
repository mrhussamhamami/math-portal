# مساعد المعلّم

موقع عربي RTL متجاوب يعمل كـ PWA ويمكن نشره مجانًا عبر GitHub Pages. يخدم مختلف المواد الدراسية وليس الرياضيات فقط.

## الميزات
- صفحات مستقلة داخل التطبيق: الرئيسية، تحضير الدرس، أوراق العمل، الوسائل التعليمية، التقويم والاختبارات، مكتبتي، الإعدادات.
- شريط تنقل سفلي، زر رجوع داخل الموقع ودعم زر الرجوع في المتصفح.
- الوضع الليلي وحجم خط قابل للتغيير.
- إنشاء نماذج محلية فورية دون الحاجة إلى خدمة ذكاء اصطناعي.
- إعدادات طباعة و«حفظ كـ PDF» من نافذة الطباعة، ومحتوى قابل للتحرير قبل الطباعة.
- مكتبة محلية، بحث، تصدير واستيراد JSON.
- دعم أساسي للعمل دون اتصال بعد أول تحميل.
- ربط اختياري بواجهة Gemini API؛ توافر المستوى المجاني وحدوده يخضعان لشروط Google الحالية.

## النشر على GitHub Pages
1. نزّل الملف المضغوط وفك الضغط.
2. افتح مستودع `mrhussamhamami/math-portal` وارفع الملفات الخمسة إلى جذر الفرع المنشور (`main`) مع استبدال الملفات القديمة عند الحاجة.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/ (root)`.
4. افتح رابط GitHub Pages وانتظر تحديث النشر.

## الذكاء الاصطناعي
من الإعدادات أضف مفتاح Gemini API ونموذجًا متاحًا لحسابك ثم احفظ. لا يوجد مفتاح مضمن في الملفات. تنبيه: أي مفتاح يدخل في واجهة موقع ثابت منشور للعامة يمكن استخراجه من المتصفح؛ استخدم مفتاحًا محدودًا وراقب الاستهلاك، والأفضل للإنتاج إنشاء وسيط خلفي يحفظ المفتاح خارج المتصفح. إنشاء المحتوى عبر API يحتاج اتصال إنترنت، بينما النماذج المحلية تعمل دون API.

## ملاحظات
المحتوى المُنشأ مسودات تحتاج مراجعة المعلم ومطابقتها للكتاب والمنهاج المعتمد قبل استخدامها في الصف. خطوط Google Fonts قد تحتاج الإنترنت، وتستخدم الأجهزة خطًا بديلًا عند انقطاعه.
